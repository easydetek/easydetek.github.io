## 产品简介

EDQ532-B 是一款面向智能照明的雷达存在感应调光调色控制器：通过 EDQ152 24GHz 雷达检测人体存在，驱动双路 PWM 输出实现灯具的**亮度调节（调光）**与**色温调节（调色）**；支持微信小程序 BLE 直连控制（易探统一标准协议）、BLE OTA 固件升级与环境光感联动。

## 核心特点

- **雷达存在检测**：EDQ152 24GHz 雷达（成品通用协议 V2.0），上报有人/无人、静止/运动状态、运动方向（靠近/远离）、目标距离与角度
- **调光调色**：冷/暖光双通道 PWM 输出，亮度 0~100% 无级调节；色温 2700K~6500K（默认 4000K），混色模型保证调节色温时总光通量恒定、体感亮度不变
- **光感联动**：板载 LTR-303 环境光传感器，环境光足够亮时人来也不开灯（节能策略，阈值可配置、可关闭）
- **BLE 直连控制**：微信小程序经易探统一标准协议直连设备，无需网关、不依赖联网
- **BLE OTA 升级**：双分区备份，失败自动回滚，支持断点续传
- **渐变与软启动**：亮度/色温变化线性渐变（默认 500ms，可配置），上电软启动渐亮，避免浪涌与体感闪烁
- **掉电记忆**：亮度、色温及各项参数持久化；无人关灯后再开灯恢复用户最后设定的色温
- **恢复出厂**：小程序命令触发，执行期间主灯呼吸指示，直至设备重启

## 功能规格

| 参数 | 规格 |
|------|------|
| 工作频率 | 24GHz（EDQ152 雷达模组） |
| 调光范围 | 0~100% 无级调节，PWM 频率不低于 2kHz（免可见频闪） |
| 色温范围 | 2700K~6500K，默认 4000K，100 级调节 |
| 环境光采集 | LTR-303 数字光传感器，开灯阈值 0~1000 lux 可调 |
| 控制方式 | BLE GATT 直连（易探统一标准协议），微信小程序 |
| 固件升级 | BLE OTA，双分区 + 失败自动回滚 + 断点续传 |
| 无人延时关灯 | 默认 300s，可配置 |
| 渐变时间 | 默认 500ms，100ms~5s 可配置 |
| 主控平台 | ESP32-C2 |
| 红外存在检测 | 预留接口，联动策略将在后续版本定义 |
