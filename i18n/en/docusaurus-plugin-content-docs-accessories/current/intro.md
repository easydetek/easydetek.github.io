# Accessories Product Line

EasyDetek accessories provide high-sensitivity light-controlled sensing solutions for high-bay and large-space lighting.

| Model | Feature | Range | Input | Mounting Height |
|-------|---------|-------|-------|-----------------|

All accessories are designed for **high-bay applications**:
- 🏭 Warehouses, factories
- 🏟️ Sports halls
- 💡 High-bay lights, canopy lights
