# Developer Resources

EasyDetek is committed to building an open sensing ecosystem, open-sourcing SDKs, example code and reference designs to help developers and integrators get started quickly.

:::info Under Construction
This section is being built. Visit the [Open Source showcase](/en/open-source) for currently published repositories.
:::

## Planned Content

- General-purpose radar sensor SDK
- Arduino / ESP32 integration examples
- KNX device description files and ETS templates
- Reference designs and hardware schematics

To add open-source project docs, create a new Markdown file in this directory (`opensource_docs/`).

:::note Note
English translation of individual project pages is in progress. The Chinese version is the authoritative source.
