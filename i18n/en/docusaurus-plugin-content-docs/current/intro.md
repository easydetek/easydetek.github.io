# Welcome to EasyDetek Tech Center

EasyDetek is dedicated to productizing microwave / mmWave radar sensing technology and building an open ecosystem. This site is organized by product line, with specs, integration guides and case studies for each.

## Product Lines

| Product Line | Description |
|--------------|-------------|
| 🔌 [Modules](/en/modules/intro) | Embedded radar modules (EDC116/EDC189C) for luminaires |
| 📡 [Sensors](/en/sensors/intro) | Standalone sensor products (EDV532/EDQ55G/H/EDQ25S-K) |
| 🔧 [Accessories](/en/accessories/intro) | Mounts, debug tools, gateways |
| 🔓 [Open Source](/en/opensource/intro) | SDKs, examples and reference designs |
