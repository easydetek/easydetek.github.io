# Product Lineup Overview

EasyDetek products are built around three layers — **Sense → Communicate → Deploy** — covering everything from radar front-end modules to finished sensors.

## Three Product Lines

### 1️⃣ Radar Sensing Modules

In-house 5.8GHz microwave / mmWave radar modules — compact and low-power, ready to embed in luminaires and devices.

- **5.8G presence-sensing module** — supports static human micro-motion detection
- Ideal for ceiling lights, downlights, cabinet lights

### 2️⃣ Finished Sensors

Ready-to-install sensor products with housing, terminals and certifications, for volume engineering projects.

- **EDV series** (e.g. EDV531 / EDV532) — high-performance microwave presence sensors
- **EDQ series** (e.g. EDQ55G / EDQ55H / EDQ55W) — multi-form motion / presence sensors
- **EDC series** (e.g. EDC116 / EDC189C) — compact embedded sensing modules
- **EDQ25S-K** — dual-tech (radar + PIR) KNX sensor

### 3️⃣ Cluster / System Solutions

Multi-device coordinated solutions for large-area or high-reliability scenarios.

- **Rail cluster solution** (EDQ55G / EDQ55H) — multi-sensor networking
- **PLC power-line communication** — wiring-free, over power lines

## Selection Guide

| Scenario | Recommended | Key Capability |
|----------|-------------|----------------|
| Ceiling light presence | EDC116 / 5.8G module | Compact, micro-motion |
| Cabinet / night light | EDC189C | Ultra-compact, low-power |
| Premium KNX smart home | EDQ25S-K | Dual-tech anti-false-alarm, KNX |
| Large-space security / cluster | EDQ55G / EDQ55H | Multi-unit networking, long range |
| Custom prototyping | EDV531 | Flexible & customizable |
