# Welcome to EasyDetek Tech Center

EasyDetek is dedicated to productizing microwave / mmWave radar sensing technology and building an open ecosystem. This site is the official technical resource hub, including:

- 📚 **Product Docs** — Specs and installation guides for each sensor and radar module
- 🛠️ **Integration** — Communication protocols, wiring, SDKs and integration guides
- 💡 **Case Studies** — Real-world deployments in lighting, security, and smart home
- 🔓 **Open Source** — Example code and reference designs for secondary development
