# Standalone Sensor Product Line

EasyDetek standalone sensors are ready-to-install products with housing and terminals, supporting AC mains / DC / Zigbee / BLE / Mi Home power and communication. They cover **5.8GHz / 24GHz / 60GHz** bands.

## Browse by Protocol

| Protocol | Representative Models | Highlights |
|----------|----------------------|------------|
| **AC mains output** | EDQ252-Y-04, EDQ282-Y-03 | Direct lamp line control, ideal for projects |
| **Tuya Zigbee** | EDQ253-Y-03, EDQ201-T-01 | Tuya ecosystem, smart home integration |
| **Mi Home** | EDQ25M-Y-01, EDQ201-M-01 | Xiaomi Mi Home APP control |
| **BLE** | ⭐ EDQ286B, EDQ253-S-01 | WeChat mini-program config, recommended |
| **Dry contact (DC)** | EDC286-Y-06, EDQ286-Y-06 | DC powered, dry contact output |

## Featured Solutions

### 🏠 Smart Home Presence Detection
- **EDQ286B** (recommended): 24GHz + BLE, shielded zone detection, WeChat mini-program
- **EDQ253-S-01** (recommended): AC + BLE, high sensitivity, ceiling recessed

### 👵 Fall Detection / Eldercare
- **EDV25P-T-02**: 60GHz, fall detection and presence, alarm system integration
- **EDV28A**: 60GHz + Cat1, breathing/heart rate monitoring, sleep stage analysis

### 🔋 Ultra-low Power Wireless
- **EDQ201-T-01 / EDQ201-M-01**: CR2450 coin cell, dual-tech (PIR + mmWave)

### 📐 Zone Detection
- **EDQ253-Y-03**: Tuya Zigbee, left-right zone detection
- **EDQ282-Y-03**: Dual-channel mains output, independent control of two lines
