# EDV151

> 体征监测｜模组

## 核心特点

体征监测

## 规格参数

| 参数 | 规格 |
|------|------|
| 感应距离 | 1m（默认0.7m） |
| 输出方式 | UART |
| 输入电压 | 3.3V |
| 输出电压 | 平均功耗≤0.1W |
| 外形尺寸 | 18*15 |

## 应用信息

| 项目 | 说明 |
|------|------|
| 细分市场 | 传感器客户,智能床,人数统计和占位探测 |
| 安装方式 | 床上 |
| 应用场景 | 卧室、康养机构 |
