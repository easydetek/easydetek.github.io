# EDC19D

> 超高灵敏度｜模组

## 核心特点

超高灵敏度

## 规格参数

| 参数 | 规格 |
|------|------|
| 感应距离 | >4m |
| 输出方式 | IO（兼容PWM） |
| 输入电压 | 5-8V |
| 输出电压 | 3.3±0.2V |
| 外形尺寸 | 20*20 |

## 应用信息

| 项目 | 说明 |
|------|------|
| 细分市场 | 光源和家居：球泡、吸顶灯、T管灯、筒灯、灯丝灯,高空市场,传感器客户,智控及系统客户 |
| 应用场景 | 仓库、厂房、体育馆 |
