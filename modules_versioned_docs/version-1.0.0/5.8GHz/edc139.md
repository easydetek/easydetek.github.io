# EDC139

> 高性能天线｜模组

## 核心特点

高性能天线

## 规格参数

| 参数 | 规格 |
|------|------|
| 感应距离 | 近档2-5m，远档4-8m |
| 输出方式 | PWM |
| 输入电压 | 7-12V |
| 输出电压 | 5/10±0.25V |
| 外形尺寸 | 59.4*16*15.2 |

## 应用信息

| 项目 | 说明 |
|------|------|
| 细分市场 | 灯具市场：三防灯、面板灯、吊线灯、导轨灯 |
