# EDQ15LK

> 支持蓝牙连接｜模组

## 核心特点

支持蓝牙连接

## 规格参数

| 参数 | 规格 |
|------|------|
| 感应距离 | 3-5m |
| 输出方式 | PWM |
| 输入电压 | 5-8V |
| 输出电压 | 0-3.3V |
| 外形尺寸 | 32*24*12 |

## 应用信息

| 项目 | 说明 |
|------|------|
| 细分市场 | 灯具市场：三防灯、面板灯、吊线灯、导轨灯 |
