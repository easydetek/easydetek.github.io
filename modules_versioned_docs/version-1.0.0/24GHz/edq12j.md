# EDQ12J

> 1.镜子灯专用
2.收发一体天线｜模组

## 核心特点

1.镜子灯专用
2.收发一体天线

## 规格参数

| 参数 | 规格 |
|------|------|
| 感应距离 | 移动/存在0.7-1.5m |
| 输出方式 | IO/UART |
| 输入电压 | 5-8V |
| 输出电压 | 3.3V |
| 外形尺寸 | 15*18 |
