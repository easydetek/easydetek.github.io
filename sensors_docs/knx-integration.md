# KNX 对接指南

适用于 EDQ25S-K 双鉴 KNX 传感器，接入 KNX 智能家居 / 楼宇系统。

## 前置条件

- KNX 总线电源
- KNX USB 接口 / IP 接口
- ETS（Engineering Tool Software）工程软件

## 接入步骤

1. **导入产品数据库**：将传感器的 `.knxprod` / 设备描述文件导入 ETS。
2. **添加设备到工程**：在 ETS 中添加 EDQ25S-K，分配物理地址。
3. **绑定组地址**：将传感器的通信对象（如「移动检测」「存在检测」「光照度」）绑定到对应组地址。
4. **下载编程**：通过总线接口将应用与参数下载到设备。
5. **功能验证**：触发传感器，观察总线上对应的报文。

## 典型联动

| 触发（传感器对象） | 联动（执行器） |
|-------------------|---------------|
| 移动检测 = ON | 灯光开启 |
| 存在检测 = OFF + 延时 | 灯光关闭 |
| 光照度 < 阈值 | 才允许开灯 |
