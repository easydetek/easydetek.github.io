## 规格参数（摘要）

| 参数 | 规格 |
|------|------|
| 工作频段 | 60GHz（57.5-61.3 GHz） |
| 感应方式 | 可见光、毫米波 |
| 输入电压 | AC 90-277V |
| 通讯方式 | 涂鸦 Zigbee |
| 调参方式 | BLE 蓝牙小程序 |
| 安装方式 | 吸顶嵌入式，标准开孔 Φ55mm |
| 产品状态 | 研发测试 |
