# EDQ251-T-Z

> 涂鸦Zigbee协议，支持左右分区探测，支持移动和存在探测｜24GHz 独立传感器｜✅ 正式量产

## 核心特点

涂鸦Zigbee协议，支持左右分区探测，支持移动和存在探测

**新命名：** EDQ251Z-Y-02
## 规格参数

| 参数 | 规格 |
|------|------|
| 工作频段 | 24GHz |
| 感应方式 | 可见光+毫米波 |
| 输入电压 | AC 90V~260V |
| 输出方式 | Tuya Zigbee |
| 调参方式 | 红外遥控器、Tuya |
| 安装方式 | 顶装明装款 |
| 产品状态 | 正式量产 |
