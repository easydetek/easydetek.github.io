# EDV25P 涂鸦 Zigbee 版

> EDV25P-T：涂鸦 Zigbee 接入（涂鸦 APP 联动），蓝牙 BLE 小程序调节，AC 90-277V 市电供电——EDV25P 系列中唯一采用交流供电的版本

涂鸦 Zigbee 版（EDV25P-T）通过标准涂鸦 Zigbee 协议接入涂鸦生态，支持涂鸦 APP 配网、状态查看与参数配置，可将有人/无人、光照与跌倒告警等状态接入涂鸦场景联动（如有人灯亮/无人灯灭、跌倒告警联动报警系统或护理平台）；设备同时保留蓝牙 BLE 与 UART 通用接口，支持小程序本地调试与参数配置。

EDV25P 系列共三个版本，硬件平台相同（57.5-61.3GHz 毫米波雷达、内置数字光照传感器），区别在于供电方式与通讯协议：

| 型号 | 供电方式 | 通讯协议 | 说明 |
|------|---------|---------|------|
| EDV25P-4 | DC 12-30V | RS485 总线（标准 Modbus 类协议） | 工业/楼宇总线组网 |
| EDV25P-K | DC 12-30V | KNX 总线（标准 KNX 楼宇协议） | KNX 智能家居/楼宇自动化 |
| **EDV25P-T** | **AC 90-277V** | **涂鸦 Zigbee 协议** | **涂鸦 APP 联动** |

:::info 在研型号
本变体在研具体型号为 **EDV25P-T-02**，当前状态：研发测试。
:::
