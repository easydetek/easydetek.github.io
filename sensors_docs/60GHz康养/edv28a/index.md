# EDV28A

> 实时探测胸腔毫米级微动，智能监测睡眠阶段，智能识别异常呼吸或心率｜60GHz 独立传感器｜🔧 研发测试

## 核心特点

实时探测胸腔毫米级微动，智能监测睡眠阶段，智能识别异常呼吸或心率

| 参数 | 规格 |

| 工作频段 | 60GHz |
| 感应方式 | 毫米波 |
