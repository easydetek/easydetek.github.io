# EDV21C RS485（Modbus）版

> EDV21C-4：RS485 总线（Modbus RTU 从站），蓝牙 BLE 小程序调节，DC 12-30V 供电，保留 Wi-Fi/MQTT 能力

RS485 版（EDV21C-4）使用 Modbus RTU 协议通过 RS485 总线通信（从站），可便捷接入 PLC、DTU、边缘网关等工业与楼宇控制设备，支持按感应区分块输出人员坐标轨迹。
