# EDV21C 标准版（WiFi MQTT）

> EDV21C-W：Wi-Fi 接入（MQTT 上云），蓝牙 BLE 小程序调节，AC 90-270V 宽压供电

标准版（EDV21C-W）为系列基础款，通过 Wi-Fi 接入网络，使用 MQTT 协议与 EasyDetek 云端/自建服务器通信，支持蓝牙小程序本地调节参数与 OTA 升级。
