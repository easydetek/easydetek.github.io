# EDV21C

> 支持人数统计，60GHz强抗干扰天线，蓝牙小程序调节｜60GHz 独立传感器｜🔧 研发测试

## 核心特点

支持人数统计，60GHz强抗干扰天线，蓝牙小程序调节

## 规格参数

| 参数 | 规格 |
|------|------|
| 工作频段 | 60GHz |
| 感应方式 | 毫米波 |
| 输入电压 | AC 90V~260V |
| 输出方式 | MQTT,BLE |
| 调参方式 | BLE |
| 安装方式 | 顶装嵌入式55mm开孔 |
| 产品状态 | 研发测试 |

## 常见问题

### 面盖是否可以覆盖标签或其他材料？

面盖尽可能不覆盖任何材料，特别是含有金属成分的电镀铝和银膜标签。
