# EDV21C KNX 版

> EDV21C-K：KNX 总线接入，蓝牙 BLE 小程序调节，DC 12-30V 辅助供电，保留 Wi-Fi/MQTT 能力

KNX 版（EDV21C-K）通过 KNX 总线接入楼宇自动化系统，配备 KNX 编程按键，可与 ETS 组态工具配合使用，实现人数统计等检测数据接入 KNX 生态。
