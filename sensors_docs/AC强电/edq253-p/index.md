# EDQ253-P

> 超高灵敏度设计，检测范围达 5m，支持力合微 PLC（PLCP）通信协议与微信小程序控制｜24GHz 独立传感器｜AC 强电供电

## 核心特点

- 超高灵敏度设计，支持人体存在检测，检测范围达 5m（挂高 3m 实测）
- 支持力合微 PLCP 通信协议（PLC 电力线通信），型号后缀 **P** 即 PLC 功能
- 微信小程序控制，扫码即用，无需网关复杂配置
- AC 90~260V 宽电压供电，火线开关输出，支持手拉手布线为其他传感器供电

:::note 测试条件
感应距离为挂高 3m、室内安装环境实测（测试人员身高 170cm、体重 65~75kg、行走速度 1m/s），不同场景安装可能造成范围变化，以实际测试为准。
:::

## 配网与配置

- **添加设备**：微信搜索小程序「连连WOWO+」，进入后点击添加设备，自动搜索设备添加，填写设备名称和位置即可
- **参数配置**：微信搜索小程序「易探雷达助手」，搜索并连接蓝牙模块后进入参数配置界面（感应半径、延时、灵敏度、安装高度、OTA 升级等）
- **恢复出厂设置**：长按按键 5s，指示灯快闪进入配网模式并恢复出厂默认值

:::note 接线说明
火线（L-L）与零线（N-N）两个端子互为连通，供电时选单火单零接入即可；如采用手拉手方式布线，可将另外两根线接入另外的 L N 端子给其他传感器供电。**不允许从感应器引线给高功率设备供电。**
:::
