# EDC59A

> 光控传感器自动开关控制｜配件

## 核心特点

光控传感器自动开关控制

## 规格参数

| 参数 | 规格 |
|------|------|
| 感应距离 | 移动感应半径 **>6m**（挂高 12m） |
| 输出方式 | PWM / IO |
| 输出电平 | 0~12V PWM / 0~10V DC |
| 工作电压 | 8~12V |
| 工作电流 | 37±2mA |
| 外形尺寸 | Ø51 × 30mm |
| 防护等级 | IP65（全防水） |
| 认证 | RoHS、REACH |

## 应用信息

| 项目 | 说明 |
|------|------|
| 细分市场 | 灯具市场、高空市场 |
| 安装方式 | 顶装，挂高 ≤12m（低于 10m 建议降低灵敏度） |
| 应用场景 | 仓库、厂房、体育馆、高空灯、高棚灯 |
