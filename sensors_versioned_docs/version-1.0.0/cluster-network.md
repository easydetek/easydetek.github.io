# 导轨集群组网

适用于 EDQ55G / EDQ55H 等导轨传感器的大空间多机协同方案。

## 适用场景

- 长走廊、地下车库
- 大型仓库、开放办公区
- 任何单台传感器覆盖不足的区域

## 组网价值

- 🔄 **无缝覆盖**：多台传感器覆盖区域拼接，消除盲区
- 🔗 **状态联动**：任一传感器触发可联动整片区域
- ⚡ **节能**：人走全灭，人来渐亮
- 🛠️ **易维护**：单点故障不影响整体

## 组网方式

EasyDetek 提供 **PLC 电力线载波** 与 **有线 / 无线** 等多种组网方式，按现场条件选择。
