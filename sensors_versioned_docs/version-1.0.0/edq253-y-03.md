# EDQ253-Y-03

> 涂鸦Zigbee无线通讯协议，支持左右分区探测｜24GHz 独立传感器｜✅ 正式量产

## 核心特点

涂鸦Zigbee无线通讯协议，支持左右分区探测

## 规格参数

| 参数 | 规格 |
|------|------|
| 工作频段 | 24GHz |
| 感应方式 | 可见光+毫米波 |
| 输入电压 | AC 90V~260V |
| 输出方式 | Tuya Zigbee |
| 调参方式 | 红外遥控器、Tuya |
| 安装方式 | 顶装嵌入式55mm开孔 |
| 产品状态 | 正式量产 |
