# EDV25P-T-02

> 支持跌倒检测、人员存在判断等，支持联动报警系统或护理平台｜60GHz 独立传感器｜🔧 研发测试

## 核心特点

支持跌倒检测、人员存在判断等，支持联动报警系统或护理平台

## 规格参数

| 参数 | 规格 |
|------|------|
| 工作频段 | 60GHz |
| 感应方式 | 可见光,毫米波 |
| 输入电压 | AC 90V~260V |
| 输出方式 | BLE,Tuya Zigbee |
| 调参方式 | BLE、Tuya |
| 安装方式 | 顶装嵌入式55mm开孔 |
| 产品状态 | 研发测试 |
