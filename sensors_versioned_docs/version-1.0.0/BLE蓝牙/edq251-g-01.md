# EDQ251-G-01

> 支持左右分区检测，支持屏蔽分区检测，小尺寸明装独立安装｜24GHz 独立传感器｜🔧 研发测试

## 核心特点

支持左右分区检测，支持屏蔽分区检测，小尺寸明装独立安装

## 规格参数

| 参数 | 规格 |
|------|------|
| 工作频段 | 24GHz |
| 感应方式 | 可见光+毫米波 |
| 输入电压 | DC 12V~24V |
| 输出方式 | 干接点、BLE |
| 调参方式 | BLE |
| 安装方式 | 顶装明装款 |
| 产品状态 | 研发测试 |
