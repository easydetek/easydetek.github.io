# EDV25P RS485（Modbus）版

> EDV25P-4：RS485 总线（标准 Modbus 类协议 / Modbus RTU 从站），蓝牙 BLE 小程序调节，DC 12-30V 供电，面向工业与楼宇总线组网

RS485 版（EDV25P-4）使用 Modbus RTU 协议通过 RS485 总线通信（从站），可便捷接入 PLC、DTU、边缘网关等工业与楼宇控制设备，支持读取全局参数、总体检测边界、感应区/屏蔽区配置与按感应区分块输出的人员坐标结果。

EDV25P 系列共三个版本，硬件平台相同（57.5-61.3GHz 毫米波雷达、内置数字光照传感器），区别在于供电方式与通讯协议：

| 型号 | 供电方式 | 通讯协议 | 说明 |
|------|---------|---------|------|
| **EDV25P-4** | DC 12-30V | RS485 总线（标准 Modbus 类协议） | 工业/楼宇总线组网 |
| EDV25P-K | DC 12-30V | KNX 总线（标准 KNX 楼宇协议） | KNX 智能家居/楼宇自动化 |
| EDV25P-T | AC 90-277V | 涂鸦 Zigbee 协议 | 涂鸦 APP 联动 |
