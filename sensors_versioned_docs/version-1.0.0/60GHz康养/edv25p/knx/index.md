# EDV25P KNX 版

> EDV25P-K：KNX 总线接入（标准 KNX 楼宇协议），蓝牙 BLE 小程序调节，DC 12-30V 供电，面向 KNX 智能家居与楼宇自动化

KNX 版（EDV25P-K）通过 KNX 总线接入楼宇自动化系统，可与 ETS 组态工具配合使用，将存在检测与跌倒检测结果接入 KNX 生态，实现有人灯亮/无人灯灭、光照联动与跌倒告警联动。设备采用 4 线接线（VCC / GND / KNX+ / KNX−），DC 12-30V 独立供电，整机功耗 ＜2W。

EDV25P 系列共三个版本，硬件平台相同（57.5-61.3GHz 毫米波雷达、内置数字光照传感器），区别在于供电方式与通讯协议：

| 型号 | 供电方式 | 通讯协议 | 说明 |
|------|---------|---------|------|
| EDV25P-4 | DC 12-30V | RS485 总线（标准 Modbus 类协议） | 工业/楼宇总线组网 |
| **EDV25P-K** | DC 12-30V | KNX 总线（标准 KNX 楼宇协议） | KNX 智能家居/楼宇自动化 |
| EDV25P-T | AC 90-277V | 涂鸦 Zigbee 协议 | 涂鸦 APP 联动 |
