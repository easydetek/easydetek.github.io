# EDV25P-T-02

> 支持跌倒检测、人员存在判断，支持联动报警系统或护理平台｜60GHz 独立传感器｜🔧 研发测试

## 核心特点

支持跌倒检测、人员存在判断，支持联动报警系统或护理平台

| 参数 | 规格 |

| 工作频段 | 60GHz |
| 感应方式 | 可见光+毫米波 |
| 输入电压 | AC 90V~260V |
