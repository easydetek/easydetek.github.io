# EDQ286B（主推）

> 支持屏蔽分区检测，支持微信小程序蓝牙配置｜24GHz 独立传感器｜✅ 正式量产

## 核心特点

支持屏蔽分区检测，支持微信小程序蓝牙配置

**新命名：** EDQ254-G-01
## 规格参数

| 参数 | 规格 |
|------|------|
| 工作频段 | 24GHz |
| 感应方式 | 可见光+毫米波 |
| 输入电压 | DC 12V~24V |
| 输出方式 | 干接点、BLE |
| 调参方式 | BLE |
| 安装方式 | 顶装嵌入式55mm开孔 |
| 产品状态 | 正式量产 |
