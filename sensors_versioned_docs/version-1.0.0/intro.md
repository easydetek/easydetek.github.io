# 独立传感器产品线

EasyDetek 独立传感器成品，即装即用，含外壳与接线端子，支持 AC 强电/DC/Zigbee/BLE/米家等多种供电与通信方式，覆盖 **5.8GHz / 24GHz / 60GHz** 全频段。

## 按通信协议浏览

| 协议 | 代表型号 | 特点 |
|------|---------|------|
| **AC 强电输出** | [EDQ252-Y-04](./edq252-y-04)、[EDQ282-Y-03](./edq282-y-03) | 直接控制灯具火线，工程首选 |
| **Tuya Zigbee** | [EDQ253-Y-03](./edq253-y-03)、[EDQ201-T-01](./edq201-t-01) | 涂鸦生态，智能家居集成 |
| **米家平台** | [EDQ25M-Y-01](./edq25m-y-01)、[EDQ201-M-01](./edq201-m-01) | 小米米家 APP 控制 |
| **BLE 蓝牙** | [EDQ286B](./edq286b)⭐、[EDQ253-S-01](./edq253-s-01)⭐ | 微信小程序配置，主推款 |
| **干接点（DC）** | [EDC286-Y-06](./edc286-y-06)、[EDQ286-Y-06](./edq286-y-06) | DC 供电，干接点输出 |

## 特色场景方案

### 🏠 智能家居存在检测
- **[EDQ286B](./edq286b)**（主推）：24GHz + BLE，支持屏蔽分区检测，微信小程序配置
- **[EDQ253-S-01](./edq253-s-01)**（主推）：AC 供电 + BLE，高灵敏度，吸顶嵌入式

### 👵 跌倒检测 / 康养监护
- **[EDV25P-T-02](./edv25p-t-02)**：60GHz，支持跌倒检测、人员存在判断，可联动报警系统
- **[EDV28A](./edv28a)**：60GHz + Cat1，监测呼吸心率，睡眠阶段分析

### 🔋 超低功耗无线
- **[EDQ201-T-01](./edq201-t-01)** / **[EDQ201-M-01](./edq201-m-01)**：CR2450 纽扣电池，双鉴协同（PIR+毫米波）

### 📐 分区探测
- **[EDQ253-Y-03](./edq253-y-03)**：涂鸦 Zigbee，支持左右分区探测
- **[EDQ282-Y-03](./edq282-y-03)**：双路强电输出，可独立控制两路灯
