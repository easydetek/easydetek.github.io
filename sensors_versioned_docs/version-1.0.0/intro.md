# 独立传感器产品线

EasyDetek 独立传感器成品，即装即用，含外壳与接线端子，支持 AC 强电/DC/Zigbee/BLE/米家等多种供电与通信方式，覆盖 **5.8GHz / 24GHz / 60GHz** 全频段。

## 特色场景方案

### 🏠 智能家居存在检测
- **[EDQ286B](/sensors/BLE%E8%93%9D%E7%89%99/edq286b)**（主推）：24GHz + BLE，支持屏蔽分区检测，微信小程序配置
- **[EDQ253-S-01](/sensors/AC%E5%BC%BA%E7%94%B5/edq253-s-01)**（主推）：AC 供电 + BLE，高灵敏度，吸顶嵌入式

### 👵 跌倒检测 / 康养监护
- **[EDV25P-T-02](/sensors/Tuya(%E6%B6%82%E9%B8%A6)/edv25p-t-02)**：60GHz，支持跌倒检测、人员存在判断，可联动报警系统
- **[EDV28A](/sensors/60GHz%E5%BA%B7%E5%85%BB/edv28a)**：60GHz + Cat1，监测呼吸心率，睡眠阶段分析

### 🔋 超低功耗无线
- **[EDQ201-T-01](/sensors/Tuya(%E6%B6%82%E9%B8%A6)/edq201-t-01)** / **[EDQ201-M-01](/sensors/Mijia(%E7%B1%B3%E5%AE%B6)/edq201-m-01)**：CR2450 纽扣电池，双鉴协同（PIR+毫米波）

### 📐 分区探测
- **[EDQ253-Y-03](/sensors/Tuya(%E6%B6%82%E9%B8%A6)/edq253-y-03)**：涂鸦 Zigbee，支持左右分区探测
- **[EDQ282-Y-03](/sensors/AC%E5%BC%BA%E7%94%B5/edq282-y-03)**：双路强电输出，可独立控制两路灯
