# 酒店客房感知方案

> 一间客房里，**谁在、在哪、几个人**，都能被感知。

酒店客房的难点不是「有没有人」，而是**分区域**判断：玄关有人进出、卫生间有人在洗澡、卧室客人躺着不动、窗帘和飘窗在动但其实没人。单一 PIR 在「静止就判无人」与「移动就误报」两端同时失守，而雷达可以在同一套硬件上给出**移动 → 静止人存 → 分区 → 坐标**四档粒度。

## 场景需求

| 需求 | 说明 | 对应能力 | 相关型号 |
|---|---|---|---|
| 分区域判断 | 玄关、卫生间、卧室各自独立上报，互不干扰 | 分点位安装 + 圆锥 / 长方体检测区 | EDQ254、EDV253 |
| 静止也「有人」 | 客人静坐、躺卧、睡眠时不能判无人 | 24GHz 人存检测 | EDQ254 |
| 抗误报 | 窗帘、飘窗、绿植、摆件、行李的移动不触发 | PIR 双鉴「与」逻辑 / 60GHz 屏蔽区 | EDQ25S、EDV253 |
| 知道几个人 | 房间实际人数，用于节能、保洁与安防策略 | 60GHz 4T4R 人员坐标 + 人数 | EDV21C |
| 接得上客控 | 干接点 / KNX / 继电器 / RS485 / MQTT | 按系列选接口 | 见[接口与接入](./interfaces.md) |

## 方案构成

| 型号 | 频段 | 本方案中的角色 | 典型点位 |
|---|---|---|---|
| [EDC286](/sensors/DC%E5%B9%B2%E6%8E%A5%E7%82%B9/edc286-y-06) | 5.8GHz + 可见光 | 只响应**移动**，做进出检测 | 玄关 / 过道 |
| EDQ254 | 24GHz + 可见光 | 移动 + **静止人存**，做区域有人判定 | 卫生间、卧室 |
| [EDQ25S](/sensors/BLE%E8%93%9D%E7%89%99/edq25s-g-01) | 24GHz + PIR | 双鉴「与」判定，做**抗误报** | 卧室（窗帘、摆件附近） |
| EDV253 | 60GHz | 长方体检测区 + **多屏蔽区**，做分区判定 | 卧室 |
| [EDV21C](/sensors/60GHz%E5%BA%B7%E5%85%BB/edv21c/) | 60GHz 4T4R | **人员坐标 + 人数**，做人数统计与轨迹计数 | 卧室、玄关 |

五款产品在本方案里的规格、检测区形态与安装要求见[核心产品](./products.md)；按房型与预算的组合见[组合方案](./combinations.md)。

- **EDQ254、EDV253 目前没有独立的单品产品页**：本方案中的参数以酒店方案册为准，建页后此处再补链接。
