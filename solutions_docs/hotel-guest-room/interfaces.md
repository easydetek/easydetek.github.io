# 接口与接入

按系列选接口，直接对接酒店系统：**干接点 / KNX / 继电器 / RS485 / MQTT / 客供 IoT 模组**。

:::info 型号后缀
同一硬件平台存在多个通讯变体，`-K`（KNX）/ `-4`（RS485 / Modbus）/ `-R`（继电器）等后缀以**选型表**为准；站内已上线的变体见各产品页。
:::

## 三条接入路径

| 接口 | 接到哪 | 典型用途 |
|---|---|---|
| 干接点 / 继电器 | 客控 **RCU** | 有人 / 无人、进出的开关量直接进客房控制器，改造成本最低 |
| KNX / RS485 | **网关 / 主机** | 总线型酒店智能化系统，按点位编址、统一管理 |
| MQTT / 客供 IoT 模组 | **云平台** | 需要人数、轨迹、房间状态等结构化数据做运营分析 |

## 调参与调试

- **BLE 小程序**：分区、屏蔽区、灵敏度、延时等参数现场可调，不需要拆吊顶。
- **MQTT**：人数、坐标、房间状态类数据上报云平台；具体报文格式见对应型号的协议文档。
