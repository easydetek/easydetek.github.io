# 行业方案

这里是**按场景**组织的方案，不是单品规格页：讲清一个空间里该装哪几款雷达、装在哪、怎么接到客控或云平台。单品参数请走[传感器产品线](/sensors/intro)或[模组产品线](/modules/intro)。

## 现有方案

| 场景 | 方案 | 一句话 |
|---|---|---|
| 酒店客房 | [酒店客房感知方案](./hotel-guest-room/index.md) | 一间客房里「谁在、在哪、几个人」都能被感知：玄关进出、卫生间与卧室人存、分区屏蔽、人数统计 |
| 办公 / 养老 / 卫浴 | 整理中 | 复用同一批雷达型号，按空间特征重新组合 |

## 每套方案的结构

1. **概述** —— 场景需求、方案构成、全流程支持
2. **核心产品** —— 本方案用到的型号，以及它们在本场景里各自的分工
3. **组合方案** —— 按房型、预算与误报容忍度给出的几种配置
4. **接口与接入** —— 干接点 / KNX / 继电器 / RS485 / MQTT 怎么接到客控系统与云平台

## 口径说明

- 方案中的型号能力以**最新规格书**为准；型号后缀（`-K` / `-4` / `-R` 等）见选型表。
- 标注「研发中」的能力尚未量产，不纳入对外承诺。
