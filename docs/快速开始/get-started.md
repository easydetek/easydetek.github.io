# 5 分钟上手对接

以一款通用串口输出型雷达传感器为例，最快完成「上电 → 检测 → 读数据」。

## 1. 准备物料

- EasyDetek 雷达传感器 / 模组 ×1
- 电源（按型号，常见 5V / 12V / 24V）
- 杜邦线 / 串口工具（USB-TTL）

## 2. 接线

| 传感器引脚 | 连接到 |
|-----------|--------|
| VCC | 电源正极（注意电压范围） |
| GND | 电源地 / 串口工具 GND |
| TX | 串口工具 RX |
| RX | 串口工具 TX（如需配置） |

:::warning 注意
上电前务必核对供电电压，超出范围可能损坏模组。具体引脚定义以型号手册为准。
:::

## 3. 上电与指示

正确上电后，传感器通常会有上电自检指示（指示灯闪烁或输出初始化报文）。

## 4. 读取检测数据

串口参数（常见默认值，具体见型号手册）：

- 波特率：115200
- 数据位 8 / 停止位 1 / 无校验

用任意串口工具（如 sscom、minicom）即可查看输出。当有人体移动 / 存在时，输出报文会发生变化。
