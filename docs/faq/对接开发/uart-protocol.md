# 串口协议常见问题

带 UART 输出的型号（如 EDC116、EDV 系列）支持串口通信。

## 基本参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 波特率 | 115200 | 部分型号可配置 |
| 数据位 | 8 | |
| 停止位 | 1 | |
| 校验位 | 无 | |
| 电平 | TTL 3.3V | **非 RS232**，不能直接接电脑串口 |

## 常见问题

### Q: 收不到串口数据？

1. **检查 TX/RX 是否接反**：传感器 TX → 主控 RX，传感器 RX → 主控 TX
2. **检查波特率**：默认 115200，确认双方一致
3. **检查电压**：TTL 3.3V 电平，USB-TTL 工具需 3.3V 档位（5V 可能损坏）
4. **检查共地**：传感器 GND 与主控 GND 必须相连

### Q: 数据乱码？

- 多半是**波特率不匹配**
- 或电平不匹配（确认是 TTL，非 RS232）

### Q: 如何配置参数（距离、灵敏度）？

- 部分型号支持串口下发配置命令
- 具体指令格式见对应型号的[规格书](/modules/intro)
- 也有型号支持红外遥控器或 BLE 蓝牙调参

### Q: 串口 vs IO 电平输出怎么选？

| 输出方式 | 优势 | 适用场景 |
|---------|------|---------|
| IO 电平 | 简单、无需通信协议 | 只需"有人/无人"判断 |
| UART 串口 | 可读距离值、状态、配置参数 | 需要精确数据或动态配置 |

## 示例代码

```python
import serial

# TTL 串口，注意电压 3.3V
ser = serial.Serial('COM3', 115200, timeout=1)

while True:
    line = ser.readline().decode(errors='ignore').strip()
    if line:
        print(f'[雷达] {line}')
        # 按型号协议解析具体字段
```
