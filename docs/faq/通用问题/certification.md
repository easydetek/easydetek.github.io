# 认证与合规

EasyDetek 产品符合多项国际认证标准。

## 常见认证

| 认证 | 适用市场 | 说明 |
|------|---------|------|
| CE | 欧盟 | 安全、健康、环保要求 |
| FCC | 美国 | 电磁兼容性 |
| RoHS | 全球 | 有害物质限制 |
| RED | 欧盟 | 无线电设备指令（5.8G/24G/60G 需此认证） |
| 北美认证 | 北美 | 部分型号（如 EDC114B 带屏蔽壳北美认证款） |

## 频段合规

EasyDetek 产品使用的频段均为 ISM（工业、科学、医疗）免授权频段：

| 频段 | 全球可用 | 备注 |
|------|---------|------|
| 5.8GHz | ✅ | 最广泛使用，各国均合规 |
| 10.5GHz | ✅ | 门锁专用 |
| 24GHz | ✅ | 部分地区有功率限制 |
| 60GHz | ✅ | 高精度检测场景 |

## 查询具体认证
