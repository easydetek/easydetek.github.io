# 微波感应和 PIR 红外感应有什么区别？

这是选型中最常见的问题。两种技术原理不同，适用场景也不同。

## 原理对比

| 维度 | 微波 / 毫米波雷达 | PIR 被动红外 |
|------|------------------|-------------|
| 检测原理 | 主动发射电磁波，检测反射的多普勒频移 | 被动接收人体红外辐射变化 |
| 穿透性 | ✅ 可穿透非金属（塑料、玻璃、木材） | ❌ 不能遮挡，需直视 |
| 温度影响 | ✅ 不受环境温度影响 | ⚠️ 高温环境灵敏度下降 |
| 微动检测 | ✅ 可检测呼吸级微动（存在感应） | ❌ 仅检测大幅移动 |
| 功耗 | 较高（需主动发射） | 极低（被动接收） |
| 成本 | 较高 | 较低 |
| 误触发 | 可能被风扇/宠物触发 | 可能被阳光/热源触发 |

## 如何选择？

- **需要"存在感应"**（静止人体也能检测）→ 选**微波/毫米波**
- **灯具内嵌、有外壳遮挡** → 选**微波**（穿透非金属外壳）
- **极端低温/高温环境** → 选**微波**（不受温度影响）
- **电池供电、超低功耗** → 选 **PIR** 或 [双鉴传感器](/sensors/intro)（PIR + 微波组合）
- **安防场景需低误报** → 选 [双鉴传感器](/sensors/intro)（两种原理同时确认才触发）
