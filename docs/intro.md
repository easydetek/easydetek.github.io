# 欢迎来到 EasyDetek 技术中心

EasyDetek 致力于微波 / 毫米波雷达传感技术的产品化与开放生态。本站点是官方技术资源中心，包含：

- 📚 **产品手册** —— 各型号传感器、雷达模组的规格参数与安装说明
- 🛠️ **开发对接** —— 通信协议、接线、SDK 与集成指南
- 💡 **应用案例** —— 吸顶灯、橱柜灯、安防、智能家居等真实落地场景
- 🔓 **开源项目** —— 示例代码、参考设计，方便二次开发
