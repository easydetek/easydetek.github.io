# 新手烧录指南：EDK60 + EDV151（零基础版）

> **本页写给完全没接触过嵌入式开发的人。**
> 全程**不需要安装任何软件**，不需要懂编程，也不需要命令行——你只要会用浏览器点按钮。
>
> 本期固件是 **EDK60 开发板 + EDV151 生命体征雷达** 的示例：烧录后用 EDV151 测心率与呼吸率。

---

## 开始之前：你手上应该有这些东西

| # | 东西 | 说明 |
|---|---|---|
| 1 | **EDK60 开发板**（ESP32-C6） | 一块小电路板，上面有 USB 口 |
| 2 | **EDV151 生命体征雷达模组** | 一块小方块，插在 EDK60 的 H3 排针上 |
| 3 | **USB 线** | 一头 USB-C，一头普通 USB |
| 4 | **一台电脑** | Windows 10/11 或 macOS |

:::warning 关于那根线
必须用**能传数据的线**。很多充电线只有电、没有数据——插上板子会亮灯，但电脑认不出来。
这是最常见的一个坑。
:::

---

## 第 0 步：检查三件事（30 秒）

### ✅ 检查 1：雷达模组插对位置了

模组要插在板子上标着 **`H3`** 的那一排针上。

:::info 为什么强调这个
板子上有两排长得差不多的针（`H3` 和 `H4`）。插错了不会烧坏，但**测不出数据**。请认准 `H3`。
:::

### ✅ 检查 2：USB 线插好了

插上后，板子上应该有**一颗绿灯**亮起来。绿灯亮 = 板子通电了。

### ✅ 检查 3：用 Chrome 或 Edge 浏览器

**必须**用这两个之一。Firefox 和 Safari 用不了。

---

## 第 1 步：烧录固件

### 打开烧录页面

在 Chrome / Edge 里打开：**[⚡ 一键烧录页面](pathname:///edk60/flash.html)**

### 点页面上的「⚡ 开始烧录」按钮

接下来会连续弹两次窗，别慌：

| 第几步 | 你会看到 | 你要做什么 |
|---|---|---|
| ① | 浏览器弹出一个**设备列表** | 选带 `USB` / `JTAG` / `COM` 字样的那一项，点「连接」 |
| ② | 页面变成进度条 | 什么都不用做，**等 10~20 秒** |
| ③ | 显示「完成 / Done」 | 成功了 ✅ |

:::tip 「烧录」是什么意思
就是把程序「装」进开发板的芯片里，相当于给新手机装好系统。
装好之后，板子一通电就会自动运行这个程序。
:::

### 烧完之后：拔一下 USB

1. **拔掉 USB 线**
2. 等 2 秒
3. **再插回去**

因为板子需要重新启动一次，才会运行新装进去的程序。

### 检查：红灯亮了吗

插回 USB 后，看板子上标着 **`RADAR`** 的**红灯**：

- **红灯亮了** ✅ → 雷达已通电，一切正常，继续第 2 步
- **红灯不亮** ❌ → 请检查 EDV151 是否插紧在 `H3` 上

---

## 第 2 步：看数据

### 打开监视页面

在同一个浏览器里打开：**[📊 实时数据显示页面](pathname:///edk60/monitor.html)**

### 点「连接设备」

跟烧录时一样，会弹出设备列表——选带 `USB` 字样的那一项，点「连接」。

### 你应该看到什么

页面会出现四个大数字：

```
距离        心率        呼吸率       体动幅度
 43 cm      75 bpm      21 bpm         4
```

### ⚠️ 重要：怎么让数据出来

**刚连上的时候，数字可能全是 `--` 或者 `0`，这是正常的。** 雷达需要时间「锁定」你的呼吸和心跳。

| 动作 | 说明 |
|---|---|
| **坐到雷达正前方** | 距离 **30~150 厘米**（大约一臂远），胸口正对雷达 |
| **保持不动** | 不要抖腿、不要晃身子、不要挥手 |
| **正常呼吸** | 不用刻意深呼吸，也不要憋气 |
| **等 20~40 秒** | 屏幕上会先出现「距离」，再过一会儿才出现「心率」「呼吸率」 |

**数据出现的顺序是这样的**（正常现象）：

```
第 1 秒    ：全都是 --      （还没检测到）
第 5 秒    ：距离 = 43cm    ← 检测到你了
第 20 秒   ：呼吸率 = 21    ← 呼吸先出来
第 30 秒   ：心率 = 75      ← 心率随后出来
```

### 怎么判断数据可信

页面上有「心率可信度」和「呼吸可信度」两个数字（0~4）：

- **可信度 ≥ 2** → 数据基本可信，可以记录
- **可信度是 0 或 1** → 继续等，或者坐得再正一点、再安静一点

:::danger 免责声明
本设备为技术演示用途，**不是医疗器械**，数据不可用于诊断或任何健康决策。
:::

## 第 3 步：想用串口工具也可以

如果你习惯用串口助手（SSCOM、XCOM、Arduino 串口监视器等都行）：

| 设置项 | 填什么 |
|---|---|
| 端口 | 那个 `USB 串行设备 (COM数字)` |
| 波特率 | **随便填**，比如 115200（走的是 USB，波特率不影响） |
| 数据位 / 停止位 / 校验 | 8 / 1 / 无 |

:::danger 串口助手用默认文本模式看，会是一屏"乱码"——这是正常的
本设备的串口上同时有两种内容，混在一起：

```text
I (5330) radar_bridge: 握手 set_gain 0.5 ... ok     <- 中文日志，可读
Z  radar_ready Z  get_time                          <- 二进制帧，显示为乱码
[45 00 01 2D 03 4B 15 ...]                          <- 体征帧，二进制
```

体征数据是 `5A + 长度 + 消息ID + 内容 + 校验` 的二进制结构，
其中的 `vital_signs` 只是夹在中间的短文本片段。
**所以用普通文本模式看，就是一屏乱码，不代表设备没工作。**
:::

### 怎么看懂数据

把串口助手切换到 **HEX + ASCII 混合显示**（或"文本/ASCII"模式），
在接收区搜索关键字 **`vital_signs`**，会看到这样的行：

```text
vital_signs 1,45,3,75,21,0,0,2,2
             |  |  |  |  |  |  |  |  |
             |  |  |  |  |  |  |  |  +- 呼吸可信度（0~4，越高越可信）
             |  |  |  |  |  |  |  +---- 心率可信度
             |  |  |  |  |  |  +------- 呼吸状态（0 正常）
             |  |  |  |  |  +---------- 心率状态（0 正常）
             |  |  |  |  +------------- 呼吸率 21 bpm
             |  |  |  +---------------- 心率 75 bpm
             |  |  +------------------- 体动幅度 3
             |  +---------------------- 距离 45 cm
             +------------------------- 睡眠状态 1（清醒）
```

对号入座：

| 你看到的 | 含义 | 要做什么 |
|---|---|---|
| `1,45,3,75,21,...` | ✅ 完全正常，正在测 | 可以记录了 |
| `1,45,3,0,0,...` | 检测到人了，但心率/呼吸还没算出来 | 坐正前方**别动**，等 30~60 秒 |
| `0,0,0,0,0,...` | 前方没有人 | 坐到雷达前方 30~150cm |

## 常见问题

### ❓ 点「开始烧录」后，设备列表是空的

按顺序试：

1. **换一根 USB 线**（90% 是这个问题——充电线不能传数据）
2. **换一个 USB 口**，台式机优先插**机箱后面**的口
3. **按住 BOOT 键再插 USB**：拔掉 USB → 按住板子上的 **BOOT** 键不放 → 插上 USB → 松开 BOOT → 再点按钮
4. 换台电脑试试

### ❓ 提示「连接失败」或进度条卡住

1. 拔掉 USB，重新插
2. **关掉可能占用串口的软件**（串口助手、Arduino IDE、其它浏览器标签页）
3. 重新点按钮

### ❓ 烧录成功了，但看不到数据

| 检查 | 怎么做 |
|---|---|
| 红灯亮不亮 | 丝印 `RADAR` 的红灯必须亮；不亮 → 模组没插好或插错排针（要插 `H3`） |
| 模组插对没 | 必须在 **`H3`**，不是 `H4` |
| 人和雷达的距离 | 30~150cm，正对雷达 |
| 有没有动 | 保持静止，等够 40 秒 |
| 选对端口没 | 要选那个 `USB 串行设备` |

### ❓ 距离有数字，但心率呼吸一直是 0

说明**雷达已经看到你了，但算不出心跳呼吸**：

1. **你在动** —— 看「体动幅度」，大于 8 就是还在动，请坐稳
2. **坐得太偏** —— 胸口要正对雷达，不要侧身
3. **距离不合适** —— 挪到 40~80cm 之间试试
4. **等得不够** —— 再多等 30 秒

如果完全不动、等了 2 分钟还是 0，请联系 [support@easydetek.com](mailto:support@easydetek.com)。

### ❓ 数字一直在跳，不稳定

- 体动幅度大 → 环境震动（风扇、桌面晃动）或人在动
- 把板子放在**稳固的桌面**上
- 人坐稳后数字会稳定

## 名词小抄（看不懂的词查这里）

| 词 | 通俗解释 |
|---|---|
| **固件 / firmware** | 装在芯片里的程序，就像手机里的系统 |
| **烧录 / flash** | 把固件「装」进芯片的动作，类似给手机刷机 |
| **端口 / COM 口** | 电脑给这个 USB 设备分配的编号，比如 `COM6` |
| **波特率 / baud** | 串口速度设置。**本设备填什么都行**，因为走的是 USB |
| **USB CDC** | 让芯片直接模拟成串口的技术，好处是**不用装驱动** |
| **H3 / H4** | 板子上两排插针的名字，印在板子的白色丝印上 |
| **丝印** | 板子上印的白色文字标记，用来认位置 |

## 备用方案：网页烧不了怎么办

如果网页方案在你电脑上实在用不了，可以用官方桌面工具：

1. 下载 **Flash Download Tool**（乐鑫官方工具）
   :::warning 版本要求
   **必须用 3.9.5 或更新的版本**，旧版本不认 ESP32-C6 芯片。
   :::
2. 打开后选择 **ESP32-C6**
3. 在表格里：
   - 文件那一栏，选固件文件 [edk60_edv151_vital.bin](pathname:///edk60/edk60_edv151_vital.bin)
   - **地址那一栏，填 `0x0`**（就一个 0x0，不要填别的）
4. 下面选 **COM 口**（那个 `USB 串行设备`）和 **BAUD 460800**
5. 点 **START**，等它跑完
6. 拔插一次 USB

:::tip 为什么只填一个地址
这份固件是**合并好的单文件**，所以只需要填一个文件、一个地址 `0x0`。
如果你在网上看到别的教程说要填三个文件、三个地址，那是**别的工程**，不适用这里。
:::
