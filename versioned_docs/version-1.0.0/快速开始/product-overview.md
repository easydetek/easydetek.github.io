# 产品体系总览

EasyDetek 产品围绕「**感知 → 通信 → 落地**」三层构建，覆盖从雷达前端模组到成品传感器的完整链路。

## 三大产品线

### 1️⃣ 雷达感应模组

自研 5.8GHz 微波 / 毫米波雷达模组，体积小、低功耗，可作为核心器件嵌入各类灯具与设备。

- **5.8G 存在感应模组** —— 支持静止人体微动检测
- 适合吸顶灯、筒灯、橱柜灯等内嵌场景

### 2️⃣ 成品传感器

即装即用的传感器成品，含外壳、接线端子与认证，面向工程批量应用。

- **EDV 系列**（如 EDV531 / EDV532）—— 高性能微波存在传感器
- **EDQ 系列**（如 EDQ55G / EDQ55H / EDQ55W）—— 多形态运动 / 存在传感器
- **EDC 系列**（如 EDC116 / EDC189C）—— 小体积嵌入式感应模组
- **EDQ25S-K** —— 双鉴（雷达 + 红外）KNX 传感器

### 3️⃣ 集群 / 系统方案

多设备协同方案，面向大面积或高可靠场景。

- **导轨集群方案**（EDQ55G / EDQ55H）—— 多传感器组网
- **PLC 电力线载波方案** —— 免布线，电力线通信

## 选型建议

| 应用场景 | 推荐产品 | 关键能力 |
|---------|---------|---------|
| 吸顶灯人体存在 | EDC116 / 5.8G 模组 | 小体积、微动检测 |
| 橱柜 / 小夜灯 | EDC189C | 极小体积、低功耗 |
| 高端 KNX 智能家居 | EDQ25S-K | 双鉴防误报、KNX 总线 |
| 大空间安防 / 导轨集群 | EDQ55G / EDQ55H | 多机组网、长距离 |
| 定制原型验证 | EDV531 | 灵活可定制 |
