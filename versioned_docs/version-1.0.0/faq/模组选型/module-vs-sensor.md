# 模组和成品传感器怎么选？

EasyDetek 同时提供嵌入式模组和即装即用的成品传感器。

## 核心区别

| 维度 | 模组（EDC/EDQ/EDV 系列） | 成品传感器（EDC286/EDQ286 等） |
|------|--------------------------|-------------------------------|
| 形态 | 裸板 PCBA，无外壳 | 含外壳、接线端子、认证 |
| 体积 | 极小（8×12mm ~ 59×16mm） | 较大（标准灯具开孔尺寸） |
| 安装 | 嵌入灯具/设备内部 | 吸顶明装/嵌入式 |
| 供电 | DC 低压（3.3-12V） | AC 强电 / DC / 电池 |
| 适用客户 | 灯具厂商、设备集成商 | 工程商、安装商、终端用户 |
| 开发门槛 | 需电路设计、程序对接 | 即装即用、接线即工作 |

## 选择建议

### 选模组的情况

- ✅ 你是**灯具厂商**，需要把感应功能嵌入灯具
- ✅ 你是**设备厂商**（门锁、马桶、镜子），需要内嵌传感器
- ✅ 你有**电路设计能力**，需要定制化集成
- ✅ 需要**极致小体积**（如 EDQ10A 仅 8×12mm）

### 选成品传感器的情况

- ✅ 你是**工程商/安装商**，需要即装即用
- ✅ 需要 **AC 强电直接控制**灯具
- ✅ 需要**智能家居平台**接入（涂鸦/米家/Zigbee/BLE）
- ✅ 需要**无需开发**的方案

## 可以混用吗？

可以。很多项目组合使用：
- 灯具内嵌模组（批量）
- 重点区域用成品传感器（如跌倒检测、分区控制）
