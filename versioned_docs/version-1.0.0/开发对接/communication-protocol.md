# 通信协议总览

EasyDetek 产品支持多种通信与输出方式，按场景选择：

| 方式 | 典型产品 | 适用场景 |
|------|---------|---------|
| 电平输出（高 / 低） | EDC116 / EDC189C | 直接驱动灯具、继电器 |
| 串口（UART） | EDV 系列 | 需读取距离 / 状态数据 |
| KNX 总线 | EDQ25S-K | KNX 智能家居 / 楼宇 |
| PLC 电力线载波 | 导轨集群方案 | 免布线、多设备 |
| 集群组网 | EDQ55G / EDQ55H | 大空间多机协同 |

:::info
各协议的详细字段定义在对应型号的产品手册中。本章节给出通用对接方法与示例。
:::
