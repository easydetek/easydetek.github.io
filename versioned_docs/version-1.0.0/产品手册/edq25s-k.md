# EDQ25S-K 双鉴 KNX 传感器

> 雷达 + 红外**双鉴**传感器，KNX 总线输出，面向高端 KNX 智能家居与楼宇。

## 核心特性

- ✅ **双鉴防误报**：微波 + 被动红外（PIR）双重确认，大幅降低误触发
- ✅ **KNX 总线**：直接接入 KNX 智能家居 / 楼宇系统
- ✅ 适合高可靠性安防与自动化场景

## 为什么用双鉴？

单一感应原理各有局限：

| 原理 | 优势 | 局限 |
|------|------|------|
| 微波 | 灵敏、可穿透非金属 | 可能被非人体运动触发（如风扇） |
| PIR | 仅对红外辐射变化响应 | 受高温环境、静止目标影响 |

**双鉴**要求两种原理同时触发才报警，可靠性显著高于单一传感器，特别适合安防与高端自动化。
