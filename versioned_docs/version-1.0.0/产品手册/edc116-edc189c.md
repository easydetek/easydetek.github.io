# EDC116 / EDC189C 嵌入式感应模组

> 超小体积嵌入式雷达感应模组，专为灯具内置集成设计（吸顶灯、橱柜灯、小夜灯等）。

## 适用场景

- 💡 LED 吸顶灯人体感应
- 🚪 橱柜灯 / 衣柜灯自动开关
- 🌙 小夜灯
- 🪞 镜灯

## 核心特性

- ✅ 极小体积，可直接嵌入灯具内部
- ✅ 低功耗，不影响灯具能效
- ✅ 微波感应，穿透非金属外壳
- ✅ 接线简单
