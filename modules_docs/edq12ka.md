# EDQ12KA

> 高灵敏度呼吸探测｜24GHz 模组

## 核心特点

高灵敏度呼吸探测

## 规格参数

| 参数 | 规格 |
|------|------|
| 工作频段 | 24GHz |
| 感应距离 | 默认5m |
| 输出方式 | IO/UART |
| 输入电压 | 5-8V DC |
| 输出电压 | 3.3V |
| 外形尺寸 | 7×38mm |

## 应用信息

| 项目 | 说明 |
|------|------|
| 细分市场 | 台灯及落地灯、镜子类、冰箱/饮水机/净化器、广告显示屏 |
| 安装方式 | 侧装1.2m |
| 应用场景 | 镜前灯、橱柜灯、闸机、广告机 |
