# EDC189C

> 感应距离稳定｜模组

## 核心特点

感应距离稳定

## 规格参数

| 参数 | 规格 |
|------|------|
| 感应距离 | 0-2m |
| 输出方式 | IO |
| 输入电压 | 5-12V |
| 输出电压 | 3.3V |
| 外形尺寸 | 20*20 |

## 应用信息

| 项目 | 说明 |
|------|------|
| 细分市场 | 光源和家居：球泡、吸顶灯、T管灯、筒灯、灯丝灯,小夜灯,户外：投光灯、壁灯、庭院灯,宠物喂食、饮水机 |
| 安装方式 | 常规挂壁1.2m |
| 应用场景 | 走廊、楼梯间、橱柜、庭院、筒灯、吸顶灯、太阳能灯、庭院灯、小夜灯、橱柜灯 |
