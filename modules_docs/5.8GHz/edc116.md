# EDC116

> 旗舰系列，挂高6米｜模组

## 核心特点

旗舰系列，挂高6米

## 规格参数

| 参数 | 规格 |
|------|------|
| 感应距离 | 6-9m |
| 输出方式 | IO/UART/PWM |
| 输入电压 | 7-12V |
| 输出电压 | 5V |
| 外形尺寸 | 20*22 |

## 应用信息

| 项目 | 说明 |
|------|------|
| 细分市场 | 光源和家居：球泡、吸顶灯、T管灯、筒灯、灯丝灯,传感器客户,户外：投光灯、壁灯、庭院灯 |
| 安装方式 | 常规3m |
| 应用场景 | 走廊、电梯口、楼梯间、球泡灯、筒灯、吸顶灯、T管灯 |
