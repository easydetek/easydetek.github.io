# EDC15SA

> 自主品牌｜模组

## 核心特点

自主品牌

## 规格参数

| 参数 | 规格 |
|------|------|
| 感应距离 | 3-5m |
| 输出方式 | IO/PWM |
| 输入电压 | 5-12V |
| 输出电压 | 3.3±0.2V |
| 外形尺寸 | 20*20 |

| 项目 | 说明 |
|------|------|
| 细分市场 | 光源和家居：球泡、吸顶灯、T管灯、筒灯、灯丝灯,消防应急市场 |
| 安装方式 | 常规3m |
| 应用场景 | 走廊、电梯口、楼梯间、球泡灯、筒灯、吸顶灯、T管灯 |
