# EDC132

> 遥控可调｜模组

## 核心特点

遥控可调

## 规格参数

| 参数 | 规格 |
|------|------|
| 感应距离 | 2-6m |
| 输出方式 | IO/PWM |
| 输入电压 | 7-12V |
| 输出电压 | 5V |
| 外形尺寸 | 22*20 |

## 应用信息

| 项目 | 说明 |
|------|------|
| 细分市场 | 光源和家居：球泡、吸顶灯、T管灯、筒灯、灯丝灯,户外：投光灯、壁灯、庭院灯 |
| 安装方式 | 常规3m |
| 应用场景 | 筒灯、宽板灯、投光灯、灯管、微波开关、天花灯、86感应开关、吸顶灯 |
