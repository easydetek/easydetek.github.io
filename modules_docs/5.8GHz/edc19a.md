# EDC19A

> 超高灵敏度  15米max｜模组

## 核心特点

超高灵敏度  15米max

## 规格参数

| 参数 | 规格 |
|------|------|
| 感应距离 | 移动8-12m |
| 输出方式 | PWM |
| 输入电压 | 5-8V DC |
| 输出电压 | 0-3.3V DC可调 |
| 外形尺寸 | 35*34.5 |

## 应用信息

| 项目 | 说明 |
|------|------|
| 细分市场 | 高空市场,传感器客户,智控及系统客户 |
| 安装方式 | 挂高≤12m |
| 应用场景 | 仓库、厂房、体育馆、高空灯、高棚灯 |
