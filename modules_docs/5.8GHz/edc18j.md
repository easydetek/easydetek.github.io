# EDC18J

> 灯丝灯专用｜模组

## 核心特点

灯丝灯专用

## 规格参数

| 参数 | 规格 |
|------|------|
| 感应距离 | 2-3m |
| 输出方式 | IO/PWM |
| 输入电压 | 5-12V |
| 输出电压 | 3.3±0.1V |
| 外形尺寸 | 直径20mm |

## 应用信息

| 项目 | 说明 |
|------|------|
| 细分市场 | 光源和家居：球泡、吸顶灯、T管灯、筒灯、灯丝灯 |
| 安装方式 | 常规3m |
| 应用场景 | 走廊、电梯口、楼梯间、灯丝灯、球泡灯、筒灯 |
