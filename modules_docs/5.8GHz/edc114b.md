# EDC114B

> 带屏蔽壳，北美认证｜模组

## 核心特点

带屏蔽壳，北美认证

## 规格参数

| 参数 | 规格 |
|------|------|
| 感应距离 | 4-6m |
| 输出方式 | IO/PWM |
| 输入电压 | 7-12V |
| 输出电压 | 5±0.1V |
| 外形尺寸 | 20*20 |

## 应用信息

| 项目 | 说明 |
|------|------|
| 细分市场 | 光源和家居：球泡、吸顶灯、T管灯、筒灯、灯丝灯 |
| 安装方式 | 常规3m |
| 应用场景 | 走廊、电梯口、楼梯间、吸顶灯、投光灯、shoplight |
