# EDV163

> 可调人存雷达｜60GHz 模组

## 核心特点

可调人存雷达

## 规格参数

| 参数 | 规格 |
|------|------|
| 工作频段 | 60GHz |
| 感应距离 | 移动/存在0-8m |
| 输出方式 | IO/UART |
| 输入电压 | 3.3V DC |
| 输出电压 | 3.3V DC |
| 外形尺寸 | 18×15mm |

## 应用信息

| 项目 | 说明 |
|------|------|
| 细分市场 | 传感器客户、户外 |
| 安装方式 | 侧装0.5-1.8m |
| 应用场景 | 卫生间、停车场占位、电话亭、投光灯、智能面板 |
