# EDQ114

> 挂高小尺寸模块｜模组

## 核心特点

挂高小尺寸模块

## 规格参数

| 参数 | 规格 |
|------|------|
| 感应距离 | 移动/存在4-4.5m |
| 输出方式 | IO/UART |
| 输入电压 | 5-8V DC |
| 输出电压 | 3.3±0.3V |
| 外形尺寸 | 14*14 |

## 应用信息

| 项目 | 说明 |
|------|------|
| 细分市场 | 灯具市场：三防灯、面板灯、吊线灯、导轨灯 |
| 安装方式 | 挂高3m |
| 应用场景 | 面板灯、吸顶灯、吊线灯、教育照明 |
