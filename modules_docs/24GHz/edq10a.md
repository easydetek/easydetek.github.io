# EDQ10A

> 超小尺寸｜模组

## 核心特点

超小尺寸

## 规格参数

| 参数 | 规格 |
|------|------|
| 感应距离 | 1-5m |
| 输出方式 | IO |
| 输入电压 | 3.3V |
| 输出电压 | 3.3V |
| 外形尺寸 | 8*12 |

## 应用信息

| 项目 | 说明 |
|------|------|
| 细分市场 | 小夜灯,镜子类市场（镜前及镜上灯、镜子灯）,智能门锁和门铃,智控及系统客户,LED驱动电源,IPC（太阳能电池摄像头类）窗户摄像头,开关面板、中控屏,厨电,宠物喂食、饮水机 |
| 安装方式 | 侧装1.2m |
| 应用场景 | 面板灯、广告机、智能门锁、橱柜灯 |
