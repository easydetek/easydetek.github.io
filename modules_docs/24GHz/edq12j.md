# EDQ12J

> 1.镜子灯专用
2.收发一体天线｜模组

## 核心特点

1.镜子灯专用
2.收发一体天线

## 规格参数

| 参数 | 规格 |
|------|------|
| 感应距离 | 移动/存在0.7-1.5m |
| 输出方式 | IO/UART |
| 输入电压 | 5-8V |
| 输出电压 | 3.3V |
| 外形尺寸 | 15*18 |

## 应用信息

| 项目 | 说明 |
|------|------|
| 细分市场 | 镜子类市场（镜前及镜上灯、镜子灯） |
| 安装方式 | 侧装1.2m |
